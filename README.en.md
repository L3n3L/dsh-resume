# dsh-resume

DeepSeek Harness plugin that lets the agent tailor campus resumes to a JD, maintain `jobhunt/` materials, tune CSS layout, and render preview HTML. You confirm and export.

Chinese user guide: [README.md](./README.md)

## Install

```sh
dsh plugin --profile web add github:L3n3L/dsh-resume
```
