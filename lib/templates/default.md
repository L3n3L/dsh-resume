# 默认简历模板说明

本文件描述模板约定，供 Agent 调整排版时遵守。

## 结构约定

1. 第一行一级标题 `# 姓名` 作为页眉主标题
2. 紧随其后的普通段落作为联系方式/摘要
3. 后续用二级标题 `## 模块名` 划分模块，例如：
   - 教育经历
   - 专业技能
   - 项目经历
   - 实习经历
   - 其他

## 样式文件

同目录 `default.css` 控制视觉样式。Agent 可以修改 CSS 来优化疏密、字号、强调色，但应保持打印友好的单栏简历布局。

## 改写原则

- 优先改 `companies/<公司>/resume.md`
- 不编造经历；素材不足时写到 `notes.md`
- 针对 JD 调整模块顺序与项目措辞
