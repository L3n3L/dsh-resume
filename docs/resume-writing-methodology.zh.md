# 校招简历写作方法论

版本：2026-09-02

这份方法论服务于 dsh-resume 的简历 Agent、MCP 工具链和人工验收。它不是某一家公司的录用规则，也不把网络经验中的数字当成硬标准。

## 一、证据分层

### 稳定共识

- 校招投递版优先做成一页 A4，保证手机和 PDF 浏览时能快速定位关键信息。
- 内容按目标岗位相关性组织，而不是把素材库原样倾倒；项目是候选池，不是必须全部展示。
- 实习和项目要写清候选人做了什么、怎么做、产生了什么结果或产物；仅有职责或技术栈不够。
- 结果优先使用可解释、可核验的数字、上线、采用、奖项、验证或作品链接；没有证据就不能补写。
- 先保证核心经历的信息量和可读性，再处理字号、间距、模块承载和文本取舍。

### 有用但属于软偏好的民间经验

- HR 通常先扫姓名/求职方向、教育、实习或项目标题、每段经历的第一条和量化结果，因此最强证据应出现在模块前部和每段首条。
- 每段经历 2–4 条高信号要点通常比 5–8 条流水账更容易阅读；本工具默认 3 条实习要点，按证据密度浮动。
- 一条 bullet 最好只有一个主要信号，避免把背景、过程、技术清单和结果写成一整段。
- 一页版可以有“信息密度”，但不等于极小字号、无分组的文字墙；底部大面积空白也属于版面失败。

### 不写进硬规则的说法

“6 秒必看完”“所有简历采用固定模块比例”“每条必须有一个数字”“固定字号或固定项目数”等说法缺少普遍适用性。它们最多用于检查提醒，不能覆盖岗位、素材质量和版面实际测量。

## 二、内容生产模型

### 经历条目

推荐句式：

> 强动词 + 对象/问题 + 我的动作或判断 + 方法/协作 + 结果/产物

背景只保留理解结果所需的最少信息。不要把 STAR 写成四段说明，而是将 STAR 压缩成一到两行、一个主要信号的简历表达。

合格的实习条目至少能回答：

1. 在什么公司/团队、什么岗位或业务场景中工作；
2. 候选人实际负责的范围是什么；
3. 至少一项可解释的结果、产物、采用、上线、验证或影响是什么。

合格的项目条目至少能回答：

1. 项目解决什么问题，服务什么用户或业务目标；
2. 候选人独立完成或主导了什么；
3. 做了哪些关键方案判断；
4. 有什么结果、上线、奖项、验证或可访问产物。

### 取舍

校园一页版的默认决策：

1. 教育经历：保留；
2. 实习经历：保留，默认每段 3 条要点，按证据密度在 2–4 条浮动；
3. 项目经历：按岗位相关性、贡献强度和差异化选择 2 个，最多 3 个；
4. 荣誉奖项：优先于技能保留，但只保留有辨识度或与岗位相关的内容；
5. 专业技能：压缩为能帮助判断岗位能力的关键词；
6. 重复、空泛修饰、低相关细节：优先删除。

用户明确指定的实习、教育或项目仍需作为目标约束处理；如果它们与一页或岗位方向冲突，Agent 应报告冲突并通过模板承载和内容重组解决，不能静默删掉或假装通过。

## 三、版面生产顺序

超出一页或出现明显空白时，严格按以下顺序：

1. 读取真实 A4 指标，确认是溢出、容器空洞、模块断裂还是内容本身过量；
2. 在用户选中的模板上微调字号、行距、页边距、模块间距和图标；
3. 仍不合适时，在原模板视觉家族上重构容器、模块并列、信息密度、流向和 CSS；
4. 重新渲染和测量；
5. 仍无法承载时，依次压缩技能、荣誉细节、重复和低相关表达；
6. 最后才讨论核心经历的合并表达；不得先删教育、实习或入选项目证据，不得用不可读字号伪造一页。

模板结构修改默认生成副本并绑定当前简历；单份简历的字号、行距、页边距和图标微调只写入该简历的呈现参数。这样既能让内容充分利用页面，又不会让同一模板下的其他简历被意外改变。

## 四、MCP 验收闭环

MCP Agent 必须完成：

`resume_prepare → resume_read → resume_check → icon_list/template_list → 模板微调或复制改造 → resume_write → resume_read → resume_check → resume_render → resume_metrics`

其中：

- `resume_check` 检查证据完整性、项目取舍和写作风险；
- `resume_render` 生成真实预览；
- `resume_metrics` 判断页数、溢出、留白和模块断裂；指标未回传时不得声称通过；
- 只有“一页 + 无溢出 + 核心证据仍完整 + 可读性正常”才能称为合格投递版。

## 五、依据与边界

稳定规则主要参考中国大学生在线、学校就业中心和人社部门的公开指导；民间经验用于补充 HR 扫描和表达习惯，不作为事实保证：

- [中国大学生在线：简历基本构成与实践经历写法](https://dxs.moe.gov.cn/zx/a/jobs_syzd/220314/1749650.shtml)
- [香港中文大学（深圳）经管学院：秋招求职全攻略](https://sme.cuhk.edu.cn/article/2348)
- [合肥工业大学：春招简历写作建议](https://jjxy.hfut.edu.cn/2023/0221/c9022a288743/page.htm)
- [上海市人力资源和社会保障局：AI 生成简历风险提示](https://rsj.sh.gov.cn/dzb/rsj/2026-02-05/pdf/03.pdf)
- [牛客：校招/暑期实习简历经验](https://www.nowcoder.com/discuss/353157805177774080)
- [牛客：一页简历与项目取舍经验](https://www.nowcoder.com/feed/main/detail/15b73f4481134037a6ab9a9d73e951f8)

这些材料共同支持“相关性、个人贡献、行动结果、可读性和人工复核”五个方向，但不支持把某一个民间数字写成所有岗位都必须遵守的规则。
