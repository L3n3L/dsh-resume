# Implementation Plan

- [ ] 1. 建立模板谱系与修订元数据
  - 为复制、保存和历史快照补充 `lineageId`、`sourceTemplateId`、`revision`。
  - 保持旧 TemplateSpec 可读取并为缺失字段提供兼容默认值。
  - _Requirement: 1, 2, 9_

- [ ] 2. 加固模板写入工具
  - 让 `template_save` 默认拒绝覆盖已有自定义模板。
  - 增加显式覆盖参数、影响摘要和新的恢复语义。
  - 确保内置模板仍然不可变，复制失败不改变当前模板。
  - _Requirement: 3, 4, 5, 6_

- [ ] 3. 将 presentation 新保存绑定到简历版本
  - 为 `presentation_save` 增加简历路径作用域。
  - 兼容旧的模板级覆盖，并让新渲染优先使用简历版本快照。
  - _Requirement: 4, 7, 8_

- [ ] 4. 完善模板库版本管理 UI
  - 展示来源、修订号、当前引用和内置不可变状态。
  - 增加“应用当前简历”“基于此模板改造”“查看版本”“另存为新模板”的清晰操作。
  - 历史恢复默认生成新修订/副本，并显示影响范围。
  - _Requirement: 2, 9, 10_

- [ ] 5. 同步提示词、MCP guide 和文档
  - 明确选定模板是改造基线，结构改造必须复制，参数微调绑定简历版本。
  - 删除“遇到困难就换模板”的隐含路径，并补充验证工序。
  - _Requirement: 1, 3, 4, 6_

- [ ] 6. 回归测试与浏览器验收
  - 覆盖工具冲突、复制、历史、旧数据、双简历隔离和 DSH 未启动 MCP 的链路。
  - 运行单测、语法检查、diff 检查，并验证模板库和预览页面关键交互。
  - _Requirement: 全部验收标准_
